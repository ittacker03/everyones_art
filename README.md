# 모두의 아트 (Everyone's Art)

## 프로젝트 소개

모두의 아트(Everyone's Art)는 사용자들이 자신의 창작물을 전시하고 다른 사용자들과 소통할 수 있는 온라인 전시 플랫폼입니다.

사용자는 직접 그림을 그리거나 자신만의 전시 공간을 꾸밀 수 있으며, 이를 다른 사용자들과 공유하여 다양한 의견을 나눌 수 있습니다. 작품 감상, 댓글 작성, 방명록 기능 등을 통해 사용자 간의 자연스러운 커뮤니티 형성을 목표로 합니다.

---

## 프로젝트 목표

- 사용자들의 창작 활동을 장려한다.
- 온라인 전시 공간을 통해 작품 공유 문화를 형성한다.
- 작품을 매개로 사용자 간 소통을 활성화한다.
- 자신만의 개성을 표현할 수 있는 전시 환경을 제공한다.

---

## 주요 기능

### 1. 메인 페이지

- 서비스 소개 제공
- 다른 사용자의 전시 공간 탐색
- 인기 전시 공간 조회
- 최근 등록된 전시 공간 조회

### 2. 회원 기능

- 회원가입
- 로그인 및 로그아웃
- 프로필 관리
- 개인 전시 공간 관리

### 3. 전시 공간 편집

- 가구 배치
- 액자 배치
- 전시대 배치
- 객체 이동
- 객체 크기 조절
- 사용자만의 전시 공간 구성

### 4. 전시 공간 관람

- 다른 사용자의 전시 공간 방문
- 전시 작품 감상
- 작품 상세 정보 확인

### 5. 작품 관리

- 작품 등록
- 작품 수정
- 작품 삭제
- 작품 설명 관리

### 6. 커뮤니티 기능

- 작품 댓글 작성
- 방명록 작성
- 즐겨찾기 등록

---

## 서비스 구조

```text
메인 페이지
│
├── 회원가입 / 로그인
│
├── 전시 공간 탐색
│   ├── 인기 전시 공간
│   └── 최신 전시 공간
│
├── 마이페이지
│   ├── 프로필 관리
│   ├── 작품 관리
│   └── 전시 공간 편집
│
└── 전시 공간
    ├── 작품 감상
    ├── 작품 상세 조회
    ├── 댓글
    └── 방명록
```
