# 모두의 아트 (Everyone's Art)

사용자가 직접 그림을 그리고, 블록으로 전시 공간을 꾸민 뒤 다른 사용자와
작품을 공유하는 웹 기반 가상 전시 서비스입니다.

## 1. 프로젝트 개요

### 주요 기능

-   회원가입 및 로그인
-   작품 제작 및 관리
-   블록 디자인 제작 및 관리
-   블록을 배치해 전시 공간 꾸미기
-   작품을 액자에 넣어 전시하기
-   다른 사용자의 전시 공간 관람
-   좋아요 및 방명록

### 기술 스택 및 데이터 저장

-   서버: Node.js, Express
-   데이터베이스: 별도 DB를 사용하지 않고 JSON 및 텍스트 파일로 저장
-   이미지 파일: 별도 파일로 저장
-   로그인 세션: `express-session` 사용
-   세션 저장소: 기본 메모리 저장소 사용을 전제로 함

브라우저를 다시 실행한 뒤 로그인 상태가 유지될 필요는 없습니다. 서버가
재시작되면 메모리 저장소의 세션도 초기화됩니다.

## 2. 페이지 구성

  페이지             기능
  ------------------ ----------------------------------
  `main`             메인 화면 및 공개 전시 공간 목록
  `gallery_list`     전시 공간 목록 및 정렬
  `gallery_user`     특정 사용자의 전시 공간 목록
  `gallery_create`   전시 공간 생성
  `item_create`      작품 제작 및 등록
  `mypage`           사용자 정보 및 개인 콘텐츠 관리
  `sign_in`          회원가입 및 로그인

세부 화면의 분리 여부와 실제 라우트 구조는 구현 과정에서 정합니다.

## 3. 회원 및 로그인

### 회원가입

-   아이디: 2\~20자
-   허용 문자: 한글, 영문, 숫자, 밑줄(`_`)
-   비밀번호: 4자 이상
-   비밀번호는 해시 처리하여 저장합니다.
-   회원가입 시 비밀번호 확인 입력란을 제공하며, 두 값이 일치해야 가입할 수 있습니다.
-   비밀번호가 일치하지 않으면 비밀번호 확인 입력란 아래에 `비밀번호가 일치하지 않습니다.`를 표시합니다.
-   아이디 형식이 올바르지 않으면 아이디 입력란 아래에 `아이디는 2~20자의 한글, 영문, 숫자, 밑줄만 사용할 수 있습니다.`를 표시합니다.
-   이미 사용 중인 아이디를 입력하면 아이디 입력란 아래에 중복 오류 메시지를 표시합니다.
-   비밀번호가 4자 미만이면 비밀번호 입력란 아래에 `비밀번호는 4자 이상이어야 합니다.`를 표시합니다.
-   별도 닉네임은 입력받지 않으며 아이디를 사용자 표시 이름으로 사용합니다.
-   가입 후 아이디 변경, 비밀번호 변경, 비밀번호 재설정 및 회원 탈퇴 기능은 제공하지 않습니다.

### 로그인

-   Express Session을 사용합니다.
-   아이디 또는 비밀번호가 틀리면 로그인 버튼 아래에 `아이디 또는 비밀번호가 올바르지 않습니다.`를 표시합니다.
-   로그인 성공 후에는 항상 메인 페이지로 이동합니다.
-   이미 로그인한 사용자가 로그인 페이지에 접근하면 안내 없이 메인 페이지로 이동합니다.
-   로그아웃은 별도 확인 없이 즉시 처리하고 메인 페이지로 이동합니다.
-   브라우저를 종료한 뒤 다시 접속했을 때 로그인 상태가 유지되지 않아도
    됩니다.
-   서버 재시작 시 기존 세션은 초기화됩니다.


## 3-1. 마이페이지 및 페이지 접근 권한

### 마이페이지

-   마이페이지에는 아이디, 가입일, 내가 만든 전시 공간 수, 내가 만든 작품 수를 표시합니다.
-   마이페이지에서 내 전시 공간 목록을 확인하고 각 전시 공간의 이름, 소개, 대표 이미지를 수정하거나 삭제할 수 있습니다.
-   마이페이지에서 내 작품 목록을 확인하고 각 작품의 제목, 설명, 그림을 수정하거나 삭제할 수 있습니다.
-   블록 디자인 관리는 마이페이지에 포함하지 않습니다.

### 상단 메뉴 및 관리 페이지 접근

-   상단 메뉴에는 `홈`, `전시 공간`, `마이페이지`, `로그인/로그아웃`을 표시합니다.
-   작품 관리 페이지는 마이페이지의 `내 작품 관리` 링크를 통해 접근합니다.
-   블록 디자인 관리 페이지는 별도 페이지로 제공하지만, 상단 메뉴에는 포함하지 않습니다. 페이지 진입 경로는 아직 결정하지 않았습니다.
-   작품 관리 및 블록 디자인 관리 페이지는 로그인한 사용자만 접근할 수 있습니다.
-   비로그인 사용자가 마이페이지, 전시 공간 생성, 작품 관리, 블록 디자인 관리 페이지에 접근하면 로그인 페이지로 이동시킵니다.
-   비로그인 사용자가 전시 공간 만들기 또는 작품 만들기 기능을 실행해도 로그인 페이지로 이동시킵니다.
-   로그인 후에는 원래 접근하려던 페이지로 돌아가지 않고 항상 메인 페이지로 이동합니다.
-   비로그인 사용자가 좋아요 버튼을 누르면 로그인 페이지로 이동시킵니다.
-   비로그인 사용자가 좋아요 또는 방명록 작성 기능을 이용하려 하면 로그인 페이지로 이동시킵니다.

## 4. 전시 공간

### 생성 및 공개

-   사용자 한 명이 생성할 수 있는 전시 공간은 최대 5개입니다.
-   전시 공간 생성 시 사용자가 이름을 직접 입력해야 합니다.
-   전시 공간 이름은 생성 후에도 수정할 수 있습니다.
-   소개 글은 선택 사항이며 최대 100자입니다.
-   모든 전시 공간은 기본적으로 공개 상태입니다.
-   전시 공간별 비공개 설정은 제공하지 않습니다.

### 대표 이미지

-   대표 이미지 업로드는 선택 사항입니다.
-   업로드하지 않으면 기본 이미지를 표시합니다.
-   허용 형식: PNG, JPG
-   최대 파일 크기: 5MB
-   업로드한 이미지는 나중에 변경할 수 있습니다.
-   목록에 표시할 때 원본 비율을 유지하면서 정해진 영역에 맞춰
    축소합니다. 이미지가 잘리지 않으며 남는 공간에는 여백이 생길 수
    있습니다.

### 전시 공간 크기

-   바닥은 처음부터 전체가 존재하는 고정된 20×20칸입니다.
-   사용자는 바닥 타일을 설치하거나 삭제할 수 없습니다.
-   전시 공간은 최대 3층까지 사용할 수 있습니다.
-   블록은 공중에 떠 있는 형태로도 설치할 수 있습니다.
-   별도의 전체 블록 개수 제한은 현재 정하지 않았습니다.

### 전시 공간 삭제

-   소유자만 자신의 전시 공간을 삭제할 수 있습니다.
-   삭제 전 확인 창을 표시합니다.
-   삭제를 확인하면 전시 공간을 즉시 삭제합니다.
-   해당 전시 공간의 블록, 액자, 방명록, 좋아요 정보도 함께 삭제합니다.
-   작품 원본 파일과 블록 디자인은 삭제하지 않습니다.

## 5. 블록 및 전시 공간 편집

### 블록 형태와 시점

-   블록 크기: 1×1×1
-   아이소메트릭 형태로 표현합니다.
-   카메라 시점은 고정합니다.
-   블록에서 보이는 면은 앞면, 옆면, 윗면입니다.
-   카메라 이동, 확대·축소, 회전은 지원하지 않습니다.
-   20×20 전시 공간 전체가 화면에 표시됩니다.

### 블록 디자인

-   기본 블록은 회색입니다.
-   사용자는 블록 디자인을 직접 제작할 수 있습니다.
-   하나의 블록 디자인은 여러 블록에서 재사용할 수 있습니다.
-   블록 디자인은 사용자별로 독립적으로 관리합니다. 다른 사용자의
    디자인은 사용할 수 없습니다.
-   사용자는 자신의 디자인을 자신이 소유한 모든 전시 공간에서 재사용할
    수 있습니다.
-   사용자당 블록 디자인 생성 개수에는 제한이 없습니다.
-   블록 디자인 복사 기능은 제공하지 않습니다.

### 블록 디자인 편집 방식

-   앞면, 옆면, 윗면 각각에 독립적인 32×32 도트 캔버스를 제공합니다.
-   앞면은 정사각형 형태로 표시합니다.
-   옆면과 윗면은 아이소메트릭 블록 면에 맞춰 왜곡된 평행사변형 형태로
    표시합니다.
-   원근 변환 방식이 아니라 도트 단위로 각 면에 매핑합니다.
-   편집 화면에는 캔버스와 아이소메트릭 블록 미리보기를 함께 표시합니다.
-   앞면, 옆면, 윗면 중 편집할 면을 선택할 수 있습니다.
-   편집 중인 내용은 미리보기에 반영하지 않습니다. 저장 버튼을 눌렀을 때만 미리보기가 갱신됩니다.
-   작품 제작과 동일한 그리기 도구를 사용합니다: 펜, 지우개, 채우기,
    전체 지우기.
-   디자인 이름은 사용자가 직접 입력하며 최대 20자입니다.
-   디자인 이름은 생성 후에도 수정할 수 있습니다.
-   디자인 목록은 최신 생성순으로 표시합니다.
-   목록에는 아이소메트릭 블록 미리보기를 표시합니다.

### 블록 디자인과 설치된 블록의 관계

-   블록은 디자인 ID(`designId`)를 참조하는 방식으로 관리합니다.
-   블록 디자인을 수정하면 해당 디자인을 사용하는 모든 블록에 변경
    사항이 반영됩니다.
-   블록 디자인을 삭제하면 해당 디자인을 사용하던 블록은 기본 회색
    블록으로 변경됩니다.
-   디자인 삭제 시 블록의 위치와 설치된 액자는 유지됩니다.
-   디자인 삭제 전 확인 창을 표시합니다.
-   디자인 수정 후 저장 버튼을 누르면 별도 확인 없이 즉시 저장합니다.
-   수정 내용을 저장하지 않고 나가면 변경 내용을 버리고 기존 디자인을 유지합니다.
-   같은 사용자의 블록 디자인끼리는 이름이 중복될 수 없습니다. 생성 및 이름 수정 시 중복을 검사합니다.

### 블록 설치 및 제거

-   설치 모드와 제거 모드를 별도 버튼으로 전환합니다.
-   현재 선택된 모드를 화면에서 구분할 수 있도록 표시합니다.
-   설치 모드에서는 빈 위치를 클릭해 블록을 설치합니다.
-   제거 모드에서는 설치된 블록을 클릭하면 제거 확인 창을 표시합니다.
-   제거를 확인하면 블록을 제거합니다.
-   제거를 취소하면 아무것도 변경하지 않습니다.
-   블록에 액자가 설치되어 있다면 블록 제거 시 해당 액자도 함께
    제거합니다.
-   블록 제거 시 액자에 연결된 작품 원본 파일은 삭제하지 않습니다.
-   이미 블록이 설치된 위치를 설치 모드에서 클릭하면 아무 동작도 하지
    않습니다. 기존 블록을 교체하지 않으며 별도 안내 메시지도 표시하지
    않습니다.
-   일반 모드에서 블록을 클릭해도 아무 동작도 하지 않습니다.
-   블록을 설치하기 전에 디자인을 선택할 수 있습니다. 디자인을 선택하지
    않으면 회색 기본 블록을 설치합니다.
-   설치된 블록의 디자인도 나중에 변경할 수 있습니다. 디자인 변경 시
    위치와 층수는 유지됩니다.

## 6. 작품 및 액자

### 작품 제작

-   작품 캔버스 크기: 512×512픽셀
-   저장 형식: PNG
-   작품 이미지 파일 용량 제한은 두지 않습니다.
-   사용자당 작품 생성 개수 제한은 없습니다.
-   작품 생성, 수정, 삭제를 지원합니다.
-   작품 제목은 필수이며 최대 20자입니다.
-   작품 설명은 선택 사항이며 최대 100자입니다.
-   작품 제목과 설명은 등록 후에도 수정할 수 있습니다.
-   같은 사용자의 작품끼리는 제목이 중복될 수 없습니다. 생성 및 제목 수정 시 중복을 검사합니다.
-   작품 복사 기능은 제공하지 않습니다.
-   작품 목록은 최신 생성순으로 표시합니다.
-   작품 수정 화면에는 기존 그림을 불러와 이어서 수정할 수 있도록
    합니다.
-   수정 내용을 저장하지 않고 나가면 변경 내용을 버리고 기존 작품을
    유지합니다.
-   펜, 지우개, 채우기, 전체 지우기 도구를 제공합니다.

### 액자 설치

-   작품을 먼저 선택한 뒤 액자 설치 모드에서 블록 앞면을 클릭해
    설치합니다.
-   액자는 블록의 앞면에만 설치할 수 있습니다.
-   옆면과 윗면에는 설치할 수 없습니다.
-   블록 앞면 하나에는 액자 하나만 설치할 수 있습니다.
-   액자는 블록 앞면의 정중앙에 고정됩니다.
-   액자 크기는 블록 앞면 가로·세로 각각 80%입니다.
-   액자는 사용자가 이동하거나 크기를 조절할 수 없습니다.
-   액자 내부에는 작품 이미지만 표시하며 작품 제목은 표시하지 않습니다.
-   작품 이미지는 액자 내부에 맞춰 축소하되 원본 비율을 유지합니다.

### 액자 제거 및 작품 교체

-   액자 제거 모드로 전환한 뒤 제거할 액자를 클릭합니다.
-   액자 제거 시 확인 창을 표시합니다.
-   확인하면 액자만 제거하고 블록과 작품 원본 파일은 유지합니다.
-   취소하면 아무것도 변경하지 않습니다.
-   빈 액자 또는 작품이 연결된 액자를 클릭해 작품 교체 기능을 실행할 수
    있습니다.
-   작품 목록에서 새 작품을 선택하면 기존 액자와 위치를 유지한 채 내부
    작품 이미지만 변경합니다.

### 작품 삭제와 빈 액자

-   작품 삭제 전 확인 창을 표시합니다.
-   작품을 삭제해도 해당 작품이 설치된 액자는 제거하지 않습니다.
-   해당 액자는 빈 액자로 남으며 내부에 `빈 액자`라는 문구를 표시합니다.
-   빈 액자에 새 작품을 연결할 수 있습니다.
-   작품 원본 파일을 삭제해도 다른 작품이나 블록에는 영향을 주지
    않습니다.

## 7. 방문자 기능: 좋아요 및 방명록

### 공개 관람 및 비로그인 권한

-   공개된 전시 공간은 누구나 관람할 수 있습니다.
-   비로그인 사용자는 관람만 가능합니다.
-   좋아요와 방명록 작성은 로그인한 사용자만 이용할 수 있습니다.
-   비로그인 사용자가 좋아요 또는 방명록 작성 기능을 이용하려 하면 로그인 페이지로 이동시킵니다.

### 좋아요

-   로그인한 사용자는 전시 공간에 좋아요를 누르거나 취소할 수 있습니다.
-   사용자 한 명은 전시 공간 하나에 좋아요를 한 번만 누를 수 있습니다.
-   같은 버튼을 다시 누르면 좋아요가 취소됩니다.
-   전시 공간에는 좋아요 개수만 표시합니다.
-   좋아요를 누른 사용자 목록은 공개하지 않습니다.
-   전시 공간 소유자도 자신의 전시 공간에 좋아요를 누르거나 취소할 수 있습니다.

### 방명록

-   로그인한 사용자만 방명록을 작성할 수 있습니다.
-   방명록 한 개의 최대 글자 수는 100자입니다.
-   최신 작성순으로 표시합니다.
-   한 페이지에 최대 10개를 표시하며, 그보다 많으면 페이지를 나눕니다.
-   작성자는 본인이 작성한 방명록을 수정하거나 삭제할 수 있습니다.
-   다른 사용자의 방명록은 수정하거나 삭제할 수 없습니다.
-   방명록 수정 시 최대 100자 제한을 다시 적용합니다.
-   수정된 방명록은 기존 작성 시간을 유지합니다.
-   방명록을 수정해도 `수정됨` 표시를 추가하지 않습니다. 원래 작성 날짜만 표시합니다.
-   방명록에는 작성자 아이디와 작성 날짜만 표시하며, 작성 시간은 표시하지 않습니다.
-   방명록에는 좋아요 기능을 제공하지 않습니다.
-   방명록은 작성자 본인만 삭제할 수 있습니다. 전시 공간 소유자라도 다른 사용자의 방명록을 삭제할 수 없습니다.
-   방명록 삭제 버튼을 누르면 확인 창을 표시합니다. 확인하면 삭제하고, 취소하면 삭제하지 않습니다.
-   방명록 작성 중 취소하면 입력한 내용을 모두 지우고 작성창을 닫습니다. 다시 작성창을 열면 빈 입력란을 표시합니다.
-   방명록 페이지에는 페이지 번호와 `이전 페이지`, `다음 페이지` 버튼을 모두 표시합니다.
-   첫 페이지에서는 `이전 페이지`, 마지막 페이지에서는 `다음 페이지` 버튼을 비활성화합니다.

## 8. 전시 공간 목록 및 정렬

전시 공간 목록에서 다음 세 가지 정렬 방식을 제공합니다.

1.  최신 등록순
2.  좋아요순
3.  오래된순

좋아요순에서 좋아요 개수가 같은 전시 공간은 최신 등록순으로 표시합니다.

## 9. 데이터 저장 방향

-   데이터베이스 대신 JSON 및 텍스트 파일을 사용합니다.
-   사용자별 전시 공간과 작품 정보를 분리해 저장합니다.
-   이미지 파일은 JSON 데이터와 별도로 저장합니다.
-   블록은 블록 디자인의 ID를 참조합니다.
-   블록 디자인을 별도 데이터로 관리하여 여러 블록에서 재사용할 수
    있도록 합니다.
-   작품 원본과 액자에 연결된 작품의 관계를 분리해 관리합니다. 작품 삭제
    시 액자는 남고 빈 액자로 바뀌어야 합니다.

구체적인 JSON 파일 구조, 파일명, 디렉터리 구조는 구현 과정에서
확정합니다.

## 10. 아직 결정하지 않은 사항

아래 항목은 다음 문답에서 계속 결정합니다.

-   비로그인 사용자의 방명록 작성 시 처리 방식
-   로그인 및 회원가입 화면의 세부 입력 검증과 오류 표시 중 아직 정하지 않은 항목
-   파일 및 JSON 데이터의 정확한 디렉터리 구조
-   작품 및 블록 디자인의 저장·수정 과정에서 발생할 수 있는 오류 처리
-   세부 UI 배치, 색상, 반응형 화면 구성
-   기타 구현에 필요한 세부 사항


## 11. 추가로 확정된 세부 사항

### 회원 및 접근 권한 보완

-   로그인하지 않은 사용자가 좋아요를 누르거나 방명록 작성을 시도하면 로그인 페이지로 이동합니다.
-   로그인 후에는 원래 요청한 페이지로 돌아가지 않고 항상 메인 페이지로 이동합니다.
-   작품 관리 페이지에서는 로그인한 사용자가 자신의 작품만 확인하고 관리할 수 있습니다. 다른 사용자의 작품은 이 페이지에서 확인하거나 관리할 수 없습니다.
-   블록 디자인 관리 페이지에서는 로그인한 사용자가 자신의 블록 디자인만 확인하고 관리할 수 있습니다. 다른 사용자의 디자인은 확인하거나 사용할 수 없습니다.
-   블록 디자인 관리 페이지의 구체적인 진입 경로는 아직 결정하지 않았습니다.

### 작품 관리 보완

-   마이페이지의 `내 작품 관리` 링크를 통해 작품 관리 페이지에 접근합니다.
-   작품 관리 페이지에서는 자신의 작품만 목록에 표시합니다.
-   작품 제목과 설명뿐 아니라 그림 이미지도 수정할 수 있습니다.
-   작품 목록은 최신 생성순으로 표시하며, 제목을 수정해도 목록 순서는 바뀌지 않습니다.
-   작품을 수정할 때 기존 그림을 불러와 이어서 그릴 수 있으며, 저장하면 기존 작품을 갱신합니다.
-   수정 내용을 저장하지 않고 나가면 변경 내용을 버리고 기존 작품을 유지합니다.
-   작품 삭제 시 확인 창을 표시합니다. 삭제를 확인하면 작품과 원본 이미지 파일을 삭제합니다.
-   작품이 연결되어 있던 액자는 삭제하지 않고 `빈 액자` 상태로 남깁니다.

### 블록 디자인 관리 보완

-   블록 디자인 이름은 같은 사용자의 디자인끼리 중복될 수 없습니다. 새로 만들거나 이름을 수정할 때 중복을 검사합니다.
-   디자인 이름을 수정하거나 디자인 내용을 편집해도 최초 생성 순서는 바뀌지 않습니다.
-   블록 디자인 목록은 최신 생성순으로 표시합니다.
-   디자인 편집 중 저장하지 않고 나가면 편집 내용을 버리고 기존 디자인을 유지합니다.
-   디자인 저장은 저장 버튼을 누르는 즉시 처리하며, 별도의 확인 창은 표시하지 않습니다.
-   미리보기는 저장 버튼을 눌렀을 때만 갱신합니다. 저장하지 않은 편집 내용은 미리보기에 반영하지 않습니다.
-   디자인 삭제 시 확인 창을 표시합니다. 삭제하면 해당 디자인을 사용하던 블록은 기본 회색 블록으로 바뀌지만, 블록의 위치와 설치된 액자는 유지합니다.

### 블록 설치 및 편집 보완

-   블록 설치 모드와 제거 모드는 별도로 전환합니다.
-   현재 선택된 모드를 화면에서 구분할 수 있도록 표시합니다.
-   설치 모드에서 이미 블록이 있는 위치를 클릭하면 아무 동작도 하지 않습니다. 기존 블록을 교체하지 않으며 별도 안내 메시지도 표시하지 않습니다.
-   일반 모드에서 블록을 클릭해도 아무 동작도 하지 않습니다.
-   블록을 설치하기 전에 사용할 디자인을 선택할 수 있습니다. 디자인을 선택하지 않으면 기본 회색 블록을 설치합니다.
-   설치된 블록의 디자인은 나중에 변경할 수 있으며, 변경해도 블록의 위치와 층수는 유지됩니다.
-   블록 제거 시 확인 창을 표시합니다. 확인하면 블록을 제거하고, 해당 블록에 설치된 액자도 함께 제거합니다. 액자에 연결된 작품 원본 파일은 삭제하지 않습니다.

### 작품 및 액자 보완

-   같은 사용자의 작품 제목은 중복될 수 없습니다. 작품 생성 및 제목 수정 시 중복을 검사합니다.
-   작품 목록은 최신 생성순으로 표시하며, 제목을 수정해도 생성 순서는 바뀌지 않습니다.
-   작품을 수정할 때 기존 그림을 불러와 이어서 수정할 수 있습니다. 저장하면 기존 작품 이미지가 갱신됩니다.
-   작품 수정 중 저장하지 않고 나가면 편집 내용을 버리고 기존 작품을 유지합니다.
-   작품 삭제 시 확인 창을 표시합니다. 작품을 삭제해도 액자는 남겨두고 `빈 액자` 문구를 표시합니다.
-   빈 액자에는 나중에 다른 작품을 연결할 수 있습니다.
-   액자 제거 모드에서 액자를 클릭하면 확인 창을 표시합니다. 확인하면 액자만 제거하고 블록과 작품 원본 파일은 유지합니다.
-   기존 액자 또는 빈 액자를 클릭해 작품 교체를 실행할 수 있습니다. 새 작품을 선택하면 액자와 위치는 유지하고 내부 이미지 만 교체합니다.

### 전시 공간 관람 및 좋아요 보완

-   공개된 전시 공간은 로그인 여부와 관계없이 누구나 관람할 수 있습니다.
-   로그인한 사용자는 전시 공간에 좋아요를 누르거나 취소할 수 있습니다.
-   전시 공간 소유자도 자신의 전시 공간에 좋아요를 누를 수 있습니다.
-   좋아요를 누른 사용자 목록은 공개하지 않고 좋아요 개수만 표시합니다.

### 방명록 보완

-   방명록은 로그인한 사용자만 작성할 수 있습니다.
-   방명록 한 개의 최대 글자 수는 100자입니다.
-   최신 작성순으로 표시하며 한 페이지에 최대 10개를 표시합니다.
-   방명록 작성자는 본인이 작성한 글만 수정하거나 삭제할 수 있습니다.
-   방명록 수정 시 원래 작성 날짜를 유지하며 `수정됨` 표시를 추가하지 않습니다.
-   방명록에는 작성자 아이디와 작성 날짜만 표시하고 작성 시간은 표시하지 않습니다.
-   방명록에는 좋아요 기능을 제공하지 않습니다.
-   방명록 작성 중 취소하면 입력한 내용을 지우고 작성창을 닫습니다.
-   방명록 삭제 전 확인 창을 표시합니다. 확인하면 삭제하고 취소하면 삭제하지 않습니다.
-   방명록 페이지 이동에는 페이지 번호와 `이전 페이지`, `다음 페이지` 버튼을 모두 제공합니다.
-   첫 페이지에서는 이전 페이지 버튼을, 마지막 페이지에서는 다음 페이지 버튼을 비활성화합니다.

-   블록 디자인 관리 페이지로 이동하는 구체적인 경로
-   정확한 JSON 파일 구조, 파일명 및 디렉터리 구조

-   세부 UI 배치, 색상 및 반응형 화면 구성


### 방명록 UI 및 페이지 이동 세부 규칙 (추가 결정)

-   방명록이 하나도 없을 때는 별도의 안내 문구를 표시하지 않고 빈 목록으로 둡니다.

-   방명록 작성 입력창 아래에 `현재 글자 수 / 100자`를 실시간으로 표시합니다.

-   방명록 수정은 목록 안에서 기존 내용이 입력창으로 바뀌는 방식으로 진행합니다.
-   수정 중 취소하면 수정 전 내용으로 되돌리고 입력창을 닫습니다.
-   수정을 완료하면 수정된 내용을 저장하고 수정 입력창을 닫습니다.
-   방명록을 수정해도 최초 작성 날짜와 목록 순서를 유지합니다. `수정됨` 표시는 하지 않습니다.
-   방명록 등록을 완료하면 작성창을 닫습니다. 새 방명록은 최신 작성순에 따라 첫 페이지에 추가되지만, 사용자가 다른 페이지를 보고 있었다면 현재 페이지에 머무릅니다.
-   방명록 페이지 이동 후에는 방명록 목록 위치로 자동 스크롤합니다.
-   페이지 번호는 현재 페이지 주변의 일부만 표시하고, 표시 범위 밖의 페이지는 `...`으로 생략합니다.
-   현재 페이지 번호는 배경색을 다르게 표시합니다.
-   첫 페이지의 `이전 페이지`와 마지막 페이지의 `다음 페이지` 버튼은 흐리게 표시하고 클릭할 수 없도록 비활성화합니다.
-   방명록 삭제 후에는 페이지 전체를 새로고침합니다.
-   방명록 수정 후에도 페이지 전체를 새로고침합니다.
-   방명록 삭제로 현재 페이지의 방명록이 하나도 남지 않으면 해당 페이지를 없애고 이전 페이지로 자동 이동합니다. 페이지 번호와 전체 페이지 수도 함께 갱신합니다.
